- 4 категория

- артқа/негізгі мәзір батырмалары
- суреттер
- автор: ХБ-31

## Жергілікті іске қосу

1. Python 3.11+ орнатыңыз.
2. `pip install -r requirements.txt`
3. `.env.example` файлын `.env` деп көшіріп, `BOT_TOKEN` енгізіңіз.
4. `python bot.py`

## Render арқылы орналастыру

Render → New → Web Service → осы жобаны GitHub арқылы қосыңыз.
Build Command:
`pip install -r requirements.txt`
Start Command:
`python bot.py`

Environment Variables:
`BOT_TOKEN` = BotFather берген токен
`BOT_AUTHOR` = `ХБ-31`

Ескерту: Render free instances тест/оқу жобаларына арналған және шектеулері бар.
